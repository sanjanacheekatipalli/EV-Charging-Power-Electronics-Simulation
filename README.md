#  EV Charging & Power Electronics Simulation
### MATLAB-Based EV Battery Charging and DC-DC Converter Simulation

A MATLAB-based simulation project developed to study the behaviour of an EV charging power stage using an averaged DC-DC buck converter model.

The project analyses EV battery charging behaviour, voltage regulation, charging current, power flow and converter efficiency.

##  Project Overview

Electric vehicle charging systems require efficient power conversion and controlled energy transfer between the DC power source and the EV battery.

This project models an EV charging power stage using MATLAB and evaluates:

 DC-DC power conversion
 EV battery voltage variation
 Charging current
 Output voltage regulation
 Input and output power
 Converter losses
 Power conversion efficiency

The simulation uses an **averaged DC-DC buck converter model** for system-level analysis.

> **Note:** This project is a MATLAB simulation model and does not represent a physical hardware prototype.


##  Project Objectives

The main objectives are:

1. Develop a MATLAB model of an EV charging DC-DC converter.
2. Study battery charging voltage behaviour.
3. Analyse charging current.
4. Evaluate input and output power.
5. Estimate converter efficiency.
6. Generate engineering plots for performance analysis.
7. Create a foundation for future EV charging and power-electronics development.
